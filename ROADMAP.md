# ROADMAP — AI English Tutor

Рабочий документ продукта. Держим здесь видение, фазы развития и приоритеты, чтобы каждый шаг кода имел смысл.

---

## Видение

Персональный AI-репетитор английского, который объединяет:

- 🎤 голосовое общение
- 📚 структурированные уроки
- 📐 грамматику
- ✍️ практику
- ❓ вопросы
- 🧩 персонализацию
- 🧠 память о пользователе
- 📈 адаптацию обучения
- 🎭 AI-персонажей

## Основной принцип

> Не строить идеального AI English Tutor в голове.
> Строить маленькую версию → дать людям → посмотреть данные → понять, что работает → изменить → повторить.

## Платформенный путь

```
Telegram Bot  →  Telegram Mini App  →  Web / Mobile App
```

**Почему Telegram первым:**
- уже знаю `aiogram`
- быстро разрабатывать
- быстро тестировать идеи
- не нужно сразу делать отдельное приложение

Telegram на первом этапе — просто интерфейс. Бизнес-логика всегда живёт отдельно от обвязки.

---

## Статус MVP — ✅ сделано

Стек: `Python` · `aiogram` · `SQLite` · `Whisper` (STT) · `LLM` (OpenAI-совместимый) · `TTS`.

Текущий цикл:

```
Пользователь говорит
      ↓
   Whisper (faster-whisper, локально)
      ↓
   LLM (провайдер выбирается в .env)
      ↓
   TTS (edge-tts)
      ↓
Пользователь получает голосовой ответ
```

Что уже работает:

- [x] текстовая и голосовая практика с исправлением ошибок и объяснением на русском
- [x] диалог с памятью последних реплик
- [x] статистика по пользователю (реплики, точность, типы ошибок)
- [x] гибкие провайдеры LLM/STT/TTS через `.env`
- [x] история и структура кода, готовая к расширению (`core/` не зависит от Telegram)

Ключевые файлы: `core/practice.py` (промпт+парсер), `bot/handlers/voice.py` (голос), `storage/sqlite.py` (данные), `providers/factory.py` (провайдеры).

### Фаза 2 — Вопросы, темы и практика — ✅ сделано

### Фаза 3 — Определение уровня — ✅ сделано
Первый урок пользователя — диагностический. ИИ определяет примерный уровень и сохраняет в БД:

`A1 → A2 → B1 → B2 → C1`

Дальнейшие уроки учитывают уровень.

Что работает:

- [x] `/diagnostic` — «лестница» из 6 заданий (2 простых, 2 средних, 2 сложных), LLM генерирует их
- [x] ответы текстом и голосом, пропуск задания, досрочное завершение
- [x] финальная оценка уровня LLM с обоснованием (strengths/weaknesses/recommendation)
- [x] запасная эвристика при сбое LLM-оценки
- [x] уровень хранится в БД (`users.level`, миграция для старых БД)
- [x] уроки генерируются под уровень: словарь, грамматика, сложность заданий (A1–C1)
- [x] уровень виден в статистике; перепрохождение через `/diagnostic`
- [x] тесты: парсеры, эвристика, сервис, миграция, форматтеры (всего 74)

### Фаза 4 — Память пользователя — ✅ сделано
Условная «RAM» пользователя. Хранить:

- уровень
- цель обучения
- интересы
- любимые темы
- ошибки
- изученную грамматику
- словарный запас
- предыдущие уроки
- сильные и слабые стороны

- особенности поведения

Пример профиля: *уровень B1 · интересы: шахматы, ML, технологии · проблемы: Present Perfect, Articles · предпочитает короткие объяснения и голосовую практику.*

Что работает:

- [x] `ProfileService` (LLM) сам ведёт профиль из обычного диалога, обновляется раз в час
- [x] профиль встраивается в промпты практики и генерации уроков (темы из интересов, слабые места в грамматике)
- [x] `/profile` и кнопка «🧠 Мой профиль»: что бот запомнил
- [x] тесты: профиль (извлечение, слияние), хранилище, форматтеры, промпты

Дальше: наполнение профиля по итогам уроков (Фаза 5) и полноценное использование в адаптивном обучении (Фаза 6).

## Тестирование идеи

Не считать продукт хорошим только потому, что нравится мне. Тестировать на:

1. себе
2. 5–10 друзьях
3. старых преподавателях английского
4. людях разных уровней

Смотреть поведение, а не слова: что понравилось, что раздражает, где перестают пользоваться, какие функции реально используют, возвращается ли человек завтра / через неделю, хочет ли продолжать.

> Не спрашивать только «Тебе понравилось?» — смотреть поведение.

## Продуктовая проверка

| Пользователь | Что понравилось | Что раздражало | Вернулся? |
|---|---|---|---|
| Друг #1 | ... | ... | Да / Нет |
| Друг #2 | ... | ... | Да / Нет |
| Учитель | ... | ... | – |
| Уровень A1 | ... | ... | Да / Нет |
| Уровень B2 | ... | ... | Да / Нет |

## Главные риски

1. Идея кажется крутой только мне → тестировать на людях.
2. Говорят «прикольно», но не возвращаются → смотреть retention.
3. Слишком много функций → делать поэтапно.
4. Скучные сгенерированные уроки → хорошие шаблоны + контроль качества.
5. AI ошибается в обучении → проверка и ограничения.
6. Дорого при росте → оптимизировать Whisper + LLM + TTS.
